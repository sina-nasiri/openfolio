3. Installation

📦 Installation is super simple! OpenFolio is a static HTML template that doesn't require any build process, dependencies, or server-side configuration.

Step 1: Extract Files

  1. Extract the downloaded ZIP file to a location on your computer
  2. You'll see the following main files and folders

Step 2: Customize Content

Edit the config.json file with your personal information:

{
  "personal": {
    "name": "Your Name",
    "title": "Your Title",
    "email": "your.email@example.com",
    ...
  }
}

Step 3: Add Your Images

Replace the placeholder images in /assets/images/:

  • headshot.jpg - Your profile photo (recommended: 400x400px)
  • og-image.jpg - Open Graph image for social sharing (recommended: 1200x630px)
  • favicon.svg - Your favicon

Step 4: Test Locally

Open index.html in your web browser, or use a local server:

# Using Python 3
python -m http.server 8000

# Using Node.js
npx http-server

# Using PHP
php -S localhost:8000

Then visit http://localhost:8000 in your browser

Step 5: Deploy

Upload all files to your web hosting via FTP/SFTP, or use one of these free hosting options:

  • GitHub Pages: Free hosting for GitHub repositories
  • Netlify: Automatic deployments from GitHub
  • Vercel: Fast deployment with CDN

4. Configuration

All content is managed through the config.json file. This makes it easy to update your portfolio without editing HTML directly.

Personal Information

{
  "personal": {
    "name": "Your Full Name",
    "firstName": "Your",
    "lastName": "Name",
    "title": "Your Professional Title",
    "subtitle": "Your Specialization",
    "email": "your.email@example.com",
    "website": "https://yourwebsite.com",
    "image": "/assets/images/headshot.jpg",
    "bio": [
      "First paragraph of your bio...",
      "Second paragraph..."
    ],
    "yearsExperience": 10,
    "projectsCompleted": 50,
    "githubStars": 100

5. Customization

Changing Colors

Edit the CSS variables in css/style.css:

:root {
  --color-primary: #10b981;      /* Main accent color */
  --color-accent: #3b82f6;       /* Secondary accent */
  --color-bg: #0a0e27;           /* Background color */
  --color-text: #e4e4e7;         /* Text color */
  --color-muted: #71717a;        /* Muted text */
  /* ... more variables */
}

Changing Fonts

The template uses two Google Fonts:

  • JetBrains Mono - For code/terminal elements
  • Inter - For body text

To change fonts:

  1. Update the Google Fonts link in index.html (line 35)
  2. Update the font-family in CSS variables

Adding/Removing Sections

Each section in index.html is independent and modular. You can:

  • Comment out sections you don't need
  • Reorder sections by moving the HTML blocks
  • Duplicate sections for additional content

Customizing Animations

Animations are controlled in js/main.js. You can adjust:

  • Animation speed and timing
  • Scroll reveal effects
  • Counter animation values
  • Typing effect speed

Adding Google Analytics

Add this code before the closing </head> tag in index.html:

<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=GA_MEASUREMENT_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'GA_MEASUREMENT_ID');
</script>

9. Troubleshooting

Common Issues and Solutions

Q: Config.json changes not showing

Solution:

  • Clear your browser cache (Ctrl+Shift+R or Cmd+Shift+R)
  • Make sure you're editing the correct config.json file
  • Check browser console for JSON syntax errors
  • Validate your JSON at jsonlint.com

Q: Images not loading

Solution:

  • Check that image paths in config.json are correct
  • Ensure images are in the /assets/images/ folder
  • Use forward slashes (/) in paths, not backslashes (\)
  • Check file extensions match actual files (.jpg, .png, etc.)

Q: Fonts not displaying correctly

Solution:

  • Ensure you have an internet connection (fonts load from Google Fonts)
  • Check if your firewall/adblocker is blocking Google Fonts
  • Try using a different browser

Q: Animations not working

Solution:

  • Check browser console for JavaScript errors
  • Ensure js/main.js is properly linked in index.html
  • Try disabling browser extensions that might interfere

Q: Mobile menu not working

Solution:

  • Clear browser cache
  • Check console for JavaScript errors
  • Ensure you haven't modified the navigation HTML structure
⚠️ Still having issues? Check the browser console (F12 → Console tab) for error messages, or contact support with details about your issue.
